# Практический цикл по доверенному ИИ — классификатор рентгенограмм COVID-19 (курс БИИ)

Бинарная классификация рентгенограмм грудной клетки (COVID / Normal) на **замороженной
базовой модели ResNet-18**, исследуемой в практическом цикле курса
«Безопасность и доверенность систем искусственного интеллекта».

В репозитории представлены **завершённый предварительный этап** (раздел 1 методических
рекомендаций) и **практическая работа №1 — исследование качества набора данных**
(раздел 2). Практические работы ПР2, ПР3 и ПР4 представлены заглушками: их можно добавить
без перестройки структуры.

---

## 1. Название проекта

## 3. Обзор

Цикл исследует доверенность одной модели на одном наборе данных: качество данных (ПР1),
устойчивость к естественным искажениям (ПР2), состязательную устойчивость (ПР3) и
приватность (ПР4). Базовая модель обучается один раз и затем **замораживается** — все
последующие эксперименты загружают один и тот же чекпойнт, поэтому наблюдаемые изменения
свойств относятся к изучаемому воздействию, а не к переобучению.

**Что включено сейчас**

1. **Предварительный этап (раздел 1)** — семь базовых шагов: аналитическая задача и
   контекст применения, описание набора данных, входная и выходная модальности,
   обучающая/валидационная/тестовая выборки, архитектура и обучение baseline, основная
   метрика качества, фиксация всех параметров эксперимента (seed, сплиты, версии
   библиотек, чекпойнт).
2. **ПР1 (раздел 2)** — количественный многомерный профиль качества: полнота,
   валидность, уникальность, утечка train↔test, баланс, качество разметки (Confident
   Learning), репрезентативность (MMD + C2ST) и аномалии изображений (BRISQUE, NIQE,
   размытие, рамки).

**Что не включено (пока):** результаты ПР2, ПР3, ПР4 и итоговый сводный отчёт. Для них
созданы папки-заглушки, чтобы будущая работа не требовала переименований и перемещений.
Сам набор данных, PDF-методички курса и исходное демонстрационное приложение здесь **не
распространяются**.

## 5. Ключевые результаты

**Baseline (предварительный этап).** ResNet-18 с инициализацией ImageNet; заморожены все
слои, кроме `layer4` и головы (`Dropout(0.5) + Linear(512→2)`); 20 эпох обучения, лучшая
эпоха — 15-я (валидационная точность 0.9917). На неизменённом тесте (720 снимков,
361 COVID / 359 Normal):

| Метрика | Значение |
|---|---|
| Accuracy **M(0)** | **0.9833** |
| 95% ДИ (Уилсон) | **[0.9711; 0.9904]** |
| Матрица ошибок | **TP 354 / FN 7 / FP 5 / TN 354** |
| Латентность инференса (CPU, batch 1) | 14.70 ± 0.81 мс на снимок |

**ПР1 (качество данных).** Основные результаты с 95%-ми интервалами:

| Свойство | Результат |
|---|---|
| Полнота | 0 нечитаемых файлов из 7200 (0.0000% [0.0000; 0.0005]) |
| Валидность | 100% grayscale; нет снимков с min-стороной < 128 px |
| Точные дубликаты (MD5) | 46 файлов = 0.6389% [0.0048; 0.0085] (34 группы) |
| Близкие дубликаты (phash + пиксельная проверка) | 262 файла = 3.6389% [0.0323; 0.0410] (199 кластеров) |
| Утечка train↔test | **7 точных + 64 близких пары** (0.12% и 1.11% от |train|) |
| Баланс (тест) | 361 / 359, imbalance ratio 0.9945, энтропия 0.6931 |
| Ошибки меток (cleanlab, 5-fold CV) | train 0/5760; test 3/720 = 0.4167% [0.0014; 0.0122] |
| Сдвиг распределений | MMD² = −0.000392, p = 0.705; C2ST AUC = 0.4885 [0.4640; 0.5139] → **сдвига нет** |
| Средние NIQE/BRISQUE | NIQE COVID 6.52 [6.31; 6.76] / Normal 5.91 [5.80; 6.02]; BRISQUE 29.06 / 29.73 |
| Аномалии | NIQE-выбросы 2.22% [0.61; 7.74]%; чрезмерно размытые 2.50% [2.16; 2.89]% |

**Как это понимать.** Данные сбалансированы и репрезентативны (сдвига нет, шум меток
пренебрежимо мал), что делает Accuracy корректной основной метрикой и обосновывает
измерение кривых устойчивости на этом тесте. В то же время 3.64% пиксельно подтверждённых
близких дубликатов и 7 + 64 пары train↔test — это реальная файловая утечка: у части
тестовых снимков есть почти идентичные двойники в обучении. Свойство зафиксировано и
учитывается при интерпретации ПР2–ПР4 (может слегка завышать устойчивость и сигнал
membership inference); утверждать, что проблема «решена», нельзя.

## 6. Быстрый старт

```bash
git clone https://github.com/minaNabil96/bi-course-covid-xray.git
cd bi-course-covid-xray
git lfs pull                       # загрузить models/baseline_model.pt

python -m pip install -r requirements.txt

# Разместите данные в data/raw/{COVID,Normal} (см. data/README.md), затем:
python scripts/reproduce_preliminary.py   # воспроизводит M(0) = 0.9833
python scripts/reproduce_pr1.py           # воспроизводит ключевые метрики ПР1
```

Требования: Python 3.13, Git LFS, ~50 МБ под чекпойнт (плюс данные). Все числа получены
на CPU/GPU, как указано в документации; инференс работает и на CPU (≈14.7 мс на снимок).

## 7. Руководство по воспроизведению

Полная пошаговая процедура — в [`docs/reproduction_guide.md`](docs/reproduction_guide.md):
предварительные требования, клонирование с LFS, получение данных, проверка SHA-256
чекпойнта, воспроизведение базовой метрики и анализа ПР1, сверка с сохранёнными
артефактами `results/`. Кратко:

1. Установить зависимости из `requirements.txt`.
2. Скачать данные и собрать `data/raw/{COVID,Normal}` (по 3600 снимков на класс).
3. Применить точные индексы сплитов из `results/preliminary/split_indices.json`.
4. Загрузить `models/baseline_model.pt` и убедиться, что M(0) = 0.9833 [0.9711; 0.9904].
5. Запустить `scripts/reproduce_pr1.py` и сверить с `results/pr1/metrics_pr1.json`.

## 12. План развития

| Этап | Тема | Статус |
|---|---|---|
| Предварительный | Базовая модель, данные, сплиты, метрика, фиксация | **готово** |
| ПР1 | Исследование качества данных (раздел 2) | **готово** |

Планируемые работы используют тот же замороженный чекпойнт, те же сплиты и ту же основную
метрику, поэтому все будущие результаты будут напрямую сопоставимы с числами выше.
